# Pokemon menu sprites

The card sprites in this directory come from the [Bulbagarden Archives Champions menu sprites category](https://archives.bulbagarden.net/wiki/Category:Champions_menu_sprites).

Salamence and Rillaboom are not present in that category, so their equivalent Scarlet and Violet menu sprites from Bulbagarden Archives are used as fallbacks. These are copyrighted game sprites and are used here for identification.
